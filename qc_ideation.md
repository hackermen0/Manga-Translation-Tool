# Ideation: The Quality Checking (QC) Tab

The QC tab is the final gatekeeper before the manga page is exported. Unlike other tabs (Detection, Redrawing, Translation, Typesetting) which are highly interactive and creative, the QC tab should be **analytical, automated, and verification-focused**. Its primary goal is to catch mistakes that a tired human eye might miss.

Here are the most impactful features to include in the QC tab to actually make a difference in the workflow:

## 1. Automated "Pre-Flight" Scan
A single button that runs a comprehensive check across the entire page and returns a dashboard of errors and warnings.

| Check Type | Description |
| :--- | :--- |
| **Overflow Detection** | Automatically flags any bubble where the translated English text overflows the polygon boundaries. |
| **Missing Translations** | Flags any detected speech bubble where the `en_text` is completely empty. |
| **Orphaned Bubbles** | Flags areas that look like speech bubbles but have no text assigned to them (missed by detection). |
| **Contrast Warning** | Checks if the text color clashes with the background (e.g., dark gray text on a black background). |

## 2. Visual Proofing Overlays
Provide specialized viewing modes designed strictly for comparing the before and after.

- **Split-Screen / Onion Skinning:** A slider that lets the user seamlessly blend the original Japanese image with the final English version. This is critical for spotting tiny background text or SFX that was completely missed during the initial detection phase.
- **Inpainting Mask Highlight:** A toggle that highlights the exact pixels that were generated by the inpainting model in neon red. This forces the user to look closely at the redrawn areas to spot AI artifacts, smudges, or poorly erased original text.

## 3. Typesetting Consistency Dashboard
When typesetting a 40-page chapter, it's easy to accidentally use different font sizes or styles for the same character.

- **Font Audit Table:** A grouped list showing every font and size used on the page. For example, if 15 bubbles use "CC Wild Words" size 16, and 1 bubble uses size 9, it will highlight the anomaly.
- **Global Style Override:** A quick way to say *"Force all bubbles on this page that are NOT explicitly marked as SFX to use CC Wild Words, Size 14."*

## 4. Linguistic Review (LQA)
- **Spell Check & Grammar:** Integrated browser or dictionary-based spell checking for the English text.
- **Text Density Map:** Highlights bubbles where the English text is aggressively squished (e.g., letter spacing < -1 or line height < 0.9) to fit into the bubble. This usually indicates a clunky, overly-literal translation that needs to be localized/shortened to read naturally.

## 5. Chapter-Level Continuity & Context Consistency
Manga translation isn't done in a vacuum. A single page needs to be contextually consistent with the rest of the chapter.
- **Terminology & Name Glossary Check:** Automatically scans the text against a project glossary. It flags if a character's name is spelled "Katsuki" on page 1 but "Katski" on page 10, ensuring uniform spelling across all pages (unless intentionally altered by the author).
- **Contextual Threading (Joke/Tone Tracking):** An AI-assisted review feature that tracks conversational threads or recurring jokes from previous pages. It warns the translator if a punchline on page 5 loses its context because the setup on page 1 was translated too literally.
- **Pronoun/Honorific Verification:** Checks if honorifics (-san, -kun, senpai) or specific pronouns remain consistent for a specific character throughout the chapter.

## 6. Export Readiness & Metadata
- **Final Render Preview:** A mock "Reader View" that simulates what the page will look like on a mobile phone vs. a desktop screen to ensure legibility.
- **Resolution Check:** Warns if the final output image resolution is too low or highly compressed.

---

### Suggested UI Layout for the Tab

1. **Top Section (The Scan Button):** A large "Run Quality Check" button.
2. **Middle Section (The Report):** An expandable accordion of issues (🛑 2 Critical Errors, ⚠️ 3 Warnings). Clicking an error immediately selects and pans the canvas to the offending bubble.
3. **Bottom Section (Visual Tools):** Toggles for Onion Skin, Original vs Final, and Inpainting Highlights.
